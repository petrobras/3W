========
Reports
========

**ThreeWToolkit** provides ``ReportGeneration`` for creating consolidated
model evaluation reports. Reports combine model information,
performance metrics, dataset split information, and configurable
visualizations into a single document.

Reports can be generated in HTML or LaTeX format.


Report Generation
=================

A report is created using the ``ReportGeneration`` class. The class
receives the trained model, dataset sizes, predictions, calculated
metrics, and an optional visualization configuration.

A basic report configuration is:

.. code-block:: python

   report = ReportGeneration(
       model=model,
       train_len=len(ds_train_transformed),
       test_len=len(ds_test_transformed),
       predictions=test_results.y_pred,
       calculated_metrics=results,
       plot_config={},
       title="Model Evaluation",
   )


Report Contents
===============

The generated report can contain information from different stages of
the machine learning workflow.

Model and Data
--------------

The report includes information about the trained model and the data
split used during evaluation. The model type and configuration are
included together with the number of training and test samples.

Performance Metrics
-------------------

Calculated performance metrics are presented in the report as a
summary of model performance.

The metrics are supplied through the ``calculated_metrics`` argument:

.. code-block:: python

   calculated_metrics = {
       "accuracy": 0.95,
   }

These values can be obtained from the model assessment stage and passed
directly to the report generator.


Visualizations
--------------

Additional visualizations can be included through ``plot_config``.
The report generation system supports several visualization types,
including:

* ``PlotSeries``
* ``PlotMultipleSeries``
* ``PlotCorrelationHeatmap``
* ``PlotFFT``
* ``SeasonalDecompose``
* ``PlotWaveletSpectrogram``

For example:

.. code-block:: python

   plot_config = {
       "PlotSeries": {
           "series": series,
           "title": "Sensor Signal",
       }
   }

The configured plots are generated automatically and incorporated into
the resulting report.


Generating Reports
==================

Reports can be generated in HTML or LaTeX format using
``generate_summary_report``.

HTML
----

An HTML report can be generated using:

.. code-block:: python

   report_html = report.generate_summary_report(
       format="html",
   )

The HTML report is generated using a Jinja2 template. The default
template is ``report_template.html``, although a different template can
be supplied through the ``template_name`` argument.

LaTeX
------

A LaTeX report can be generated using:

.. code-block:: python

   report_latex = report.generate_summary_report(
       format="latex",
   )

The LaTeX report is constructed as a Beamer presentation and includes
the model performance, model configuration, data split, and configured
visualizations.


Saving Reports
==============

Reports can be saved after generation using ``save_report``:

.. code-block:: python

   report.save_report(
       doc=report_html,
       filename="model_evaluation",
       format="html",
   )

For LaTeX output:

.. code-block:: python

   report.save_report(
       doc=report_latex,
       filename="model_evaluation",
       format="latex",
   )

The generated report files are stored in a report-specific directory.
Visualization files are stored alongside the generated report to keep
the output self-contained and portable.


Automatic Export
================

Reports can also be configured to be saved automatically when they are
generated by setting ``export_report_after_generate``:

.. code-block:: python

   report = ReportGeneration(
       model=model,
       train_len=len(ds_train_transformed),
       test_len=len(ds_test_transformed),
       predictions=test_results.y_pred,
       calculated_metrics=results,
       plot_config=plot_config,
       title="Model Evaluation",
       export_report_after_generate=True,
   )


Report Workflow
===============

The report generation workflow can be summarized as:

1. Train and evaluate the model.
2. Obtain predictions on the test dataset.
3. Calculate the desired performance metrics.
4. Configure the visualizations to include.
5. Create a ``ReportGeneration`` instance.
6. Generate the report in HTML or LaTeX format.
7. Save the generated report when required.

This workflow allows model evaluation results to be consolidated into
a reproducible report without requiring the individual metrics and
visualizations to be assembled manually.

For a complete example of assessment and report generation, see the
corresponding tutorial.
